# Colecciones

Guarda aquí la colección de peticiones que usaste para navegar tu API.

- **Bruno**: crea la colección dentro de esta carpeta, por ejemplo en `colecciones/bruno/`. Bruno guarda cada petición como un archivo `.bru`; súbelos tal cual.
- **Postman**: exporta la colección (*Export > Collection v2.1*) y guárdala como `colecciones/postman.json`.
- **Insomnia**: exporta la colección y guárdala como `colecciones/insomnia.json` o `.yaml`.

Usa una variable para la URL base, por ejemplo `{{base}}` con el valor `https://tu-api.onrender.com`, así la misma colección sirve contra tu Codespace y contra Render.
