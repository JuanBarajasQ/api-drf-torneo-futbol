# Evidencias

Guarda aquí tus capturas de pantalla, con estos nombres. En todas debe verse la URL de tu API en Render (la que termina en `onrender.com`).

| Archivo | Qué debe mostrar |
|---|---|
| `01-raiz.png` | `GET /api/` con la lista de tus recursos |
| `02-lista-paginada.png` | una lista con `count`, `next`, `previous` y `results` |
| `03-filtro-busqueda-orden.png` | una petición con filtro, búsqueda u orden en la URL y su resultado |
| `04-crear-201.png` | un POST válido que responde 201 |
| `05-validacion-400.png` | un POST que rompe una regla de tu variante y el error que devuelve |
| `06-action.png` | una de tus `@action` funcionando |
| `07-swagger.png` | tu documentación en `/api/docs/` |

Puedes usar `.png` o `.jpg`. Lo que importa es que el nombre empiece por el número.
